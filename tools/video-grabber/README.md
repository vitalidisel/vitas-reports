# video-grabber — מהטלפון ישר למחשב

שולחים קישור לסרטון מהטלפון (יוטיוב, יוטיוב שורטס, אינסטגרם, פייסבוק, טיקטוק),
והמחשב בבית מוריד את הסרטון באיכות מקסימלית ושומר אותו בתיקייה של הפלטפורמה.

אין צורך להתקין אפליקציה בטלפון: הטלפון שולח את הקישור דרך **טלגרם** — כפתור ה"שיתוף"
שקיים ממילא בכל אפליקציה. הבוט הוא שלך בלבד, רץ על המחשב שלך, ואף אחד אחר לא יכול להשתמש בו.

```
   📱 טלפון                    ☁️ טלגרם                  💻 המחשב שלך
 שיתוף → הבוט   ─────────►   מעביר את ההודעה   ─────────►  yt-dlp מוריד
                                                            ושומר לתיקייה
                             ◄─────────  "✅ נשמר: ...\YouTube\..." ◄
```

עובד מכל מקום — לא צריך שהטלפון והמחשב יהיו על אותה רשת. צריך רק שהמחשב יהיה דלוק ומחובר לאינטרנט.

---

## התקנה (פעם אחת, ~5 דקות)

### 1. יוצרים בוט בטלגרם
בטלפון, בטלגרם, פותחים צ'אט עם **@BotFather**:
1. שולחים `/newbot`
2. בוחרים שם (למשל *הורדות של ויטאס*) ושם-משתמש שמסתיים ב-`bot`
3. מעתיקים את הטוקן שהוא שולח — שורה כמו `123456789:ABCdef...`

### 2. מריצים את ההתקנה על המחשב
מורידים את התיקייה `tools/video-grabber` למחשב, ואז:
לחיצה ימנית על **`setup.ps1`** → *Run with PowerShell*.

(אם ווינדוס חוסם: פותחים PowerShell בתיקייה ומריצים `powershell -ExecutionPolicy Bypass -File setup.ps1`)

הסקריפט:
- מוודא ש-Python 3 מותקן (ומתקין דרך winget אם צריך)
- מוריד ל-`bin\` את `yt-dlp.exe` ואת `ffmpeg` — שניהם נדרשים לאיכות מלאה
- מבקש את הטוקן ואת תיקיית השמירה (ברירת מחדל: `%USERPROFILE%\Videos\Downloads`)
- מציע להגדיר הפעלה אוטומטית בכל כניסה למחשב

### 3. מחברים את הטלפון
מריצים **`start.bat`**. בהרצה הראשונה יופיע בחלון קוד בן 6 ספרות.
פותחים בטלגרם את הבוט שיצרתם ושולחים לו את הקוד — וזהו.
מאותו רגע רק המשתמש הזה מורשה, וכל אחד אחר שינסה יקבל סירוב.

## שימוש יומיומי

באפליקציה (יוטיוב / אינסטגרם / פייסבוק / טיקטוק) → **שיתוף** → טלגרם → הצ'אט של הבוט.
הבוט עונה בהודעה אחת שמתעדכנת בזמן אמת:

```
⬇️ מוריד — Instagram · 🎬 וידאו
▓▓▓▓▓▓▓░░░░░ 62%
```

ובסיום:

```
✅ נשמר במחשב — Instagram · 🎬 וידאו
מודעת קמפיין קיץ 2026
👤 vitas.marketing · ⏱ 0:31 · 💾 18.4 MB
📁 C:\Users\you\Videos\Downloads\Instagram\2026-07-15 vitas.marketing - מודעת קמפיין [DTx9].mp4
```

אפשר לשלוח כמה קישורים בהודעה אחת — הם יורדו בזה אחר זה.

### פקודות

| פקודה | מה היא עושה |
|---|---|
| `/mp3 <קישור>` | להוריד אודיו בלבד (MP3 באיכות מקסימלית) |
| `/status` | מה יורד עכשיו וכמה מחכים בתור |
| `/cancel` | ביטול ההורדה הנוכחית וריקון התור |
| `/last` | 5 ההורדות האחרונות והנתיבים שלהן |
| `/where` | לאן נשמרים הקבצים |
| `/cookies chrome\|edge\|firefox\|off` | להשתמש בהתחברות מהדפדפן שבמחשב |
| `/help` | תפריט העזרה |

### איך הקבצים מסודרים

```
Downloads\
├── YouTube\
│   └── Shorts\
├── Instagram\
├── Facebook\
├── TikTok\
├── Twitter\
└── Other\
```

שם קובץ: `תאריך-פרסום יוצר - כותרת [מזהה].mp4` — כך שמיון לפי שם הוא גם מיון כרונולוגי,
והמזהה בסוף מונע דריסה של שני סרטונים עם אותה כותרת.

## מודעות של קמפיינים (פייסבוק / אינסטגרם)

זה מה שהכלי הזה בעיקר משרת, ולכן שווה לדעת שתי נקודות:

**1. תוכן שדורש התחברות.** הרבה מודעות ופוסטים באינסטגרם ובפייסבוק לא נגישים למי שלא מחובר.
שולחים לבוט `/cookies chrome` (או `edge` / `firefox`) והוא ישתמש בהתחברות מהדפדפן שבמחשב.
חשוב: הדפדפן צריך להיות **סגור** בזמן ההורדה, אחרת הוא נועל את קובץ הקוקיז.
זה נותן לכלי גישה לסשן שלך ברשתות — להפעיל רק אם זה בסדר מבחינתך; `/cookies off` מבטל.

**2. קישורי Meta Ad Library.** קישור מסוג `facebook.com/ads/library/?id=...` הוא עמוד של ספריית
המודעות, לא סרטון, ולרוב לא יעבוד ישירות. הדרך שעובדת: לפתוח את המודעה בספרייה, ללחוץ עליה
כדי להגיע לפוסט עצמו, ולשתף את הקישור לפוסט. אם אין קישור לפוסט — הבוט יגיד שהקישור לא נתמך.

## הגדרות (`config.json`)

```jsonc
{
  "bot_token": "...",            // הטוקן מ-BotFather
  "allowed_user_ids": [12345],   // מי מורשה. ריק = מצב צימוד בהרצה הבאה
  "download_dir": "C:\\Users\\you\\Videos\\Downloads",
  "folder_per_platform": true,   // false = הכול בתיקייה אחת
  "default_format": "video",     // "audio" = הכול יורד כ-MP3 כברירת מחדל
  "cookies_from_browser": "",    // "chrome" / "edge" / "firefox" / ""
  "max_filesize_mb": 0,          // 0 = בלי הגבלה
  "history_size": 500,
  "auto_update_ytdlp": true      // עדכון yt-dlp בכל עלייה של הבוט
}
```

הקובץ מכיל את הטוקן — הוא ב-`.gitignore` ולא נכנס לריפו. אם הטוקן דלף, שולחים ל-@BotFather
`/revoke` ומעדכנים את הקובץ.

## תפעול

- **הבוט רץ ברקע?** ההתקנה יוצרת משימה מתוזמנת בשם `video-grabber` שעולה בכל כניסה למחשב.
  בדיקה: `Get-ScheduledTask video-grabber`. עצירה: `Stop-ScheduledTask -TaskName video-grabber`.
  ביטול לגמרי: `uninstall-autostart.ps1`.
- **לוגים:** `logs\grabber.log` (מתחלף אוטומטית), והיסטוריית הורדות ב-`logs\history.jsonl`.
- **עדכון:** הבוט מריץ `yt-dlp -U` בכל עלייה. אתרים משנים את עצמם תדיר, ולכן אם הורדה נכשלת
  פתאום — הפעלה מחדש של הבוט פותרת את זה ברוב המקרים.
- **בדיקות:** `python tests\test_grabber.py` — 21 בדיקות שרצות בלי רשת ובלי טלגרם (yt-dlp מדומה).

### תקלות נפוצות

| מה רואים | מה לעשות |
|---|---|
| "אין לך הרשאה" | המשתמש לא מורשה. מרוקנים `allowed_user_ids` ב-config.json ומריצים מחדש כדי לצמד מחדש |
| "התוכן דורש התחברות" | `/cookies chrome` (והדפדפן סגור) |
| "חסר ffmpeg" | להריץ שוב `setup.ps1` |
| הבוט לא עונה | לוודא שהמחשב דלוק, ולהסתכל ב-`logs\grabber.log` |
| הורדה נתקעת ב-0% | לרוב חסימה זמנית של האתר — `/cancel` ולנסות שוב בעוד כמה דקות |
