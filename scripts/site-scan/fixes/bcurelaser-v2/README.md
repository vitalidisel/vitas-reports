# תיקונים לדף הנחיתה bcurelaser-v2 (WordPress + Elementor)

המשך ל[דוח הסריקה](../../reports/bcurelaser-v2-2026-09-05/README.md). החבילה מחולקת לשניים:

1. **תוסף וורדפרס** `bcure-lp-fixes.zip` — כל מה שאפשר לתקן בקוד בלי לגעת בעיצוב. פועל רק על הדף 15964 (bcurelaser-v2) ולא נוגע בשאר האתר.
2. **צ'קליסט לאלמנטור** — מה שחייבים לעשות בעורך (כותרת H1, טריגר הפופאפ, תמונות, טראקרים).

התוסף נבדק מול הדף החי (הזרקת ה-CSS/JS שלו בסימולציית iPhone 13). צילומים ב-`preview/`.

## 2. התקנה (5 דקות)

**א. להעלות את התוסף**
1. וורדפרס → תוספים → הוסף חדש → העלאת תוסף → `bcure-lp-fixes.zip` → הפעל.
2. לפתוח את הקובץ לעריכה (תוספים → עורך קבצי תוספים → B-Cure LP Fixes) או ב-SFTP: `wp-content/plugins/bcure-lp-fixes/bcure-lp-fixes.php`, ולמלא את הבלוק "הגדרות" בראש הקובץ:

```php
const BCURE_LP_PHONE    = '03-1234567';      // טלפון לחיוג. ריק = בלי כפתור
const BCURE_LP_WHATSAPP = '972501234567';    // וואטסאפ, בינלאומי בלי +
const BCURE_LP_TITLE       = 'בי-קיור לייזר | 30 ימי התנסות בהחזר כספי מלא';
const BCURE_LP_DESCRIPTION = '...';          // עד ~155 תווים
const BCURE_LP_OG_IMAGE    = 'https://lp.bcurelaser.co.il/wp-content/uploads/.../share-1200x630.jpg';
```

אם `BCURE_LP_OG_IMAGE` נשאר ריק התוסף ישתמש ב"תמונה מומלצת" של הדף (להגדיר בעריכת הדף → תמונה מומלצת, 1200×630).

**ב. חלופה בלי תוסף** — Elementor Pro → הגדרות אתר → Custom Code: להדביק את ה-CSS (מהפונקציה `bcure_lp_css`) ב-`<head>` ואת ה-JS (`bcure_lp_js`, עם השורה `window.BCURE_LP = {...}` לפניו) ב-`</body>`. זה מכסה הכול חוץ מ-title/description/OG ו-alt, שדורשים PHP (אפשר להדביק את החלק הזה בתוסף Code Snippets).

**ג. לאמת** — לפתוח את הדף בגלישה בסתר במובייל: הפופאפ נפתח אחרי 5 שניות בלי באנר מעליו; אחרי סגירתו הבאנר מופיע בעברית מעל הפס הדביק; בפס יש טלפון ווואטסאפ. ואז להריץ שוב את הסריקה:

```
NODE_USE_ENV_PROXY=1 node scripts/site-scan/scan.mjs https://lp.bcurelaser.co.il/bcurelaser-v2/ --via-node --out /tmp/scan
```

## 3. מה חייבים לעשות באלמנטור (לפי סדר חשיבות)

### הפופאפ (ממצא #1)
תבניות → פופאפים → הפופאפ 19547 ("קונים PLUS") → הגדרות (גלגל שיניים) → **Triggers**:
- לכבות **On Page Load** (כרגע 5 שניות).
- להדליק **On Scroll → Direction: Down, Within: 40%** או **On Page Load 15–20 שניות**, ובמובייל עדיף **On Exit Intent** לא קיים — לכן לשקול **Advanced → Show up to 1 times** (פעם אחת למבקר) ו-**Avoid Multiple Popups**.
- לשקול **Advanced → Prevent Closing on Overlay: Off** ולהגדיל את ה-X ל-44px.

### כותרת ה-hero כטקסט אמיתי (ממצא #2)
הסקשן הראשון הוא תמונה אחת (`Hero_He_Desktop.png-מתוקן.png` / `Hero_He_Tablet`). לבנות אותו מחדש:
1. תמונת רקע: הרקע התכלת + המכשיר בלבד (בלי טקסט).
2. ווידג'ט **Heading** עם HTML Tag = **H1**: "הטכנולוגיה החדשנית לטיפול בכאבים".
3. Heading H2 / Text: "עכשיו בידיים שלך", "B-Cure Laser Pro — לוקחים את טכנולוגיית ה-LLLT המתקדמת שלנו לרמה הבאה".
4. תג "30 ימי התנסות בהחזר כספי מלא" כווידג'ט Icon Box או Heading עם רקע עגול.
5. אחרי זה למחוק את ה-H1 המוסתר: `BCURE_LP_SR_H1 = ''` בתוסף.
בדסקטופ הטקסט הקטן שבתמונה ("טכנולוגיה מתקדמת להאצת תהליכי החלמה") לא קריא במובייל — כטקסט הוא ייגלל ויתאים למסך.

### תמונות (ממצא #7)
- **ספריית מדיה → alt** לתמונות: hero, המוצר, 4 לוגואי הספקים, 8 thumbnails של הווידאו, 5 האייקונים. התוסף ממלא alt מכותרת הקובץ, אבל שמות כמו `maxresdefault-2` לא עוזרים לאף אחד.
- **לוגואי "ספקים מורשים"**: בווידג'ט התמונה → Image Size = **Medium (300px)** במקום Full (Be Pharm נשלח 1665×1292 ומוצג 67×100).
- **Thumbnails של הווידאו** (מומחים ממליצים, סיפורי הצלחה): Image Size = **Medium** או Custom 400×400.
- תמונת המוצר בסקשן "לא בטוחים": Image Size = **Medium_Large**.

### באנר העוגיות (ממצא #3)
התוסף מתרגם בצד הלקוח. הפתרון הקבוע: Zoho CRM → Setup → Marketing → Website Tracking / Google Ads (הסקריפט `zcga.js`) → Cookie consent → לערוך את הטקסט ואת שמות הכפתורים לעברית. אם הבאנר לא נדרש (אין קהל אירופי), לשקול לכבות אותו שם ולהסיר 22% מהמסך במובייל.

### טראקרים ומשקל (ממצא #6)
27 דומיינים צד-שלישי בכל טעינה: GTM, Zoho CRM, Zoho PageSense, Facebook, Google Ads, Analytics, Outbrain, Taboola, Clarity. שתי פעולות:
1. להעביר את כל הפיקסלים שלא נמצאים ב-GTM (Outbrain, Taboola, Clarity, PageSense) לתוך הקונטיינר `GTM-N35Z3L68`, ולהגדיר להם טריגר **Window Loaded** או **Scroll Depth**. ככה הם לא מתחרים ב-LCP.
2. לבדוק עם המדיה-באייר האם Outbrain/Taboola/Clarity עדיין פעילים. כל אחד שלא — למחוק.
בנוסף: Elementor → הגדרות → Features → להדליק **Optimized CSS Loading**, **Optimized Gutenberg Loading**, ו-Performance → **Lazy Load Background Images**.

### GTM4WP (ממצא #10)
האזהרות בקונסולה מגיעות מהתוסף GTM4WP כשה-"Container code placement" על **Off** בעוד הקונטיינר מוזרק ידנית. לא שובר כלום. כדי להשתיק: GTM4WP → General → Container code placement = **Custom** (ואז להשאיר את ההזרקה הידנית), או להזין שם את ה-ID ולהסיר את הסניפט הידני מה-Custom Code.

### תיקון לדוח: ה-FAQ (ממצא #11)
בבדיקה חוזרת ה-FAQ הוא ווידג'ט Toggle של אלמנטור עם `role="button"` ו-`aria-expanded` — נגיש כמו שצריך. ה"קישורים המתים" האמיתיים הם רק כפתורי Accept/Deny של Zoho. אין מה לעשות כאן.

## 4. הגרסה המתוקנת של הדף (עבודה על עותק)

`output/bcurelaser-v2-fixed.json` הוא ייצוא האלמנטור של הדף אחרי התיקונים שאפשר לעשות ב-JSON (נוצר ע"י `transform.py` מהקובץ ב-`source/`):

- **hero חדש מטקסט אמיתי**: H1 "הטכנולוגיה החדשנית לטיפול בכאבים", H2 "עכשיו בידיים שלך", פסקת B-Cure Laser Pro, תג "30 ימי התנסות" (HTML+CSS), ותמונת המוצר הקיימת (`Good-Energies-B-Cure-Laser-Pro-110-1`) על רקע גרדיאנט תכלת עם עיגולים ב-CSS. שתי עמודות בדסקטופ, נערם במובייל. הדמיה: `preview/hero-new-desktop-mock.png`.
- ווידג'ט התמונה הריק של המובייל ב-hero הישן הוסר.
- לוגואי "ספקים מורשים": גודל תמונה **medium** במקום full. תמונת המוצר בסקשן "לא בטוחים": **medium_large**.
- ה-CSS של הדף (`overflow-x:hidden`) עבר מ-`.elementor-15964` ל-`selector`, אחרת הוא לא היה חל על העותק.

**מה לא בקובץ הזה** (חייבים בעורך): thumbnails של הווידאו (נמצאים בתבנית Loop 12592, לא בדף), alt בספריית המדיה, וטריגר הפופאפ (הגדרות התצוגה של פופאפ לא נכללות בייצוא — 2 לחיצות בעורך, ראו סעיף 3). את קובץ הפופאפ אין צורך לייבא.

### ייבוא ופרסום על עותק
1. תבניות → תבניות שמורות → **ייבוא תבניות** → `output/bcurelaser-v2-fixed.json`.
2. עמודים → הוסף חדש → כותרת "bcurelaser-v2 test" → ערוך עם אלמנטור → בהגדרות הדף (גלגל שיניים): פריסת עמוד = **Elementor Canvas**, ולהסתיר כותרת.
3. הוספת תבנית (סמל התיקייה) → "ביקיור לייזר v2 — מתוקן" → הוסף. **לא** לסמן "Apply settings" אם מוצע, ה-CSS של הדף כבר בתבנית.
4. לפרסם עם slug זמני `bcurelaser-v2-test` (הכתובת מתחילה ב-`bcurelaser-v`, אז התוסף פועל עליה). לשלוח לי את הכתובת לסריקה.
5. אחרי אישור: עמודים → הדף הישן → קישור קבוע `bcurelaser-v2-old`; הדף החדש → `bcurelaser-v2`. הפופאפ מוצג לפי תנאי התצוגה שלו — לוודא ב-Templates → Popups → Conditions שהוא חל גם על הדף החדש (אם התנאי הוא "כל האתר" אין מה לשנות).
