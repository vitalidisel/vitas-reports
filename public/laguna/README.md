# תמונות דף הנחיתה LAGUNA

התמונות כאן הן **תמונות ממלא מקום** שנחתכו ממוקאפ העיצוב — הן ברזולוציה נמוכה
ומיועדות רק כדי שהדף (`/laguna`) יעבוד מקצה לקצה.

לפני עלייה לאוויר יש להחליף אותן בקבצי המקור מהאדריכל/הצלם, באותם שמות:

| קובץ | שימוש | מומלץ |
| --- | --- | --- |
| `slide-1..5.jpg` | תמונות הגלריה הגדולות | לפחות 1600px רוחב |
| `thumb-1..5.jpg` | הרצועה המוקטנת בצד הגלריה | ~5:4, לפחות 240px רוחב |

מספר השקופיות והטקסטים החלופיים (alt) מוגדרים במערך `SLIDES` בקובץ
`app/laguna/LagunaLanding.jsx`.
